## 🎯 特性

- 战术元素（球员、球、路线等）
- 工具栏(选择、绘制、标注等常用工具)
- 属性面板 (实时调整元素属性和样式)
- 动画演示功能
- 自动保存（浏览器缓存）
- 移动设备适配
- 导出为 PNG
- PWA

## 🔨 开发

```sh
#克隆项目
git clone https://github.com/CJ-cooper6/coco-tacticx.git

#安装依赖
yarn install

#启动开发服务器
yarn run dev
```
